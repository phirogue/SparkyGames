# Text Length & Game Psychology — Applied Findings

*Compiled 2026-07-31. Part A answers "how much text on story cards"; Part B
distills the game-psychology canon into ranked, ethical applications.*

## Part A — Story text: the numbers

Key evidence: 79% of users scan rather than read (NN/g); mobile comprehension
needs ~half desktop length; players skip text when it stalls their
actions-per-minute — but **tap-to-advance turns reading INTO action**. Hades
ships 305,000 words experienced as 1–3 sentence sips; 80 Days shows 40–80
words/screen with a choice every 1–3 screens; Lifeline beats are 10–30 words;
Reigns cards run 5–25 words. Subtitle standards: ~38 chars/line, max 2–3
lines visible.

**Ashcat story-card budget (adopted as writing law):**

| Parameter | Value |
|---|---|
| Words per tap-line | **8–14** (hard cap 18) |
| Rendered lines visible at once | 1–2, max 3 |
| Tap-lines per story card | **3–5** (sweet spot 4) |
| Words per card total | **30–60**, hard cap 80 |
| Cards between gameplay | 1–2 (2–3 at chapter climaxes) |
| Story time per run | ≤20–25% (~45–60s of a 3–5 min run) |
| Choice labels | 1–4 words ideally, short always |
| Reveal | instant on tap; always skippable; keep a log |

**Compression craft:** cut drafts by half; the art carries the nouns (never
describe what the illustration shows); subtext over statement ("She didn't
ask about the ninth life."); one concrete detail beats three adjectives; end
each line on the destabilizing word; delete the first sentence (throat-
clearing); read each card aloud in <10 seconds.

## Part B — Psychology canon, applied ethically

| Principle | Our application | Line we don't cross |
|---|---|---|
| Schell's lenses (curiosity, interest curve, juice) | Every run ends posing a question; biggest choice in the final third; extraction gets the best audiovisual beat | — |
| Koster (fun = pattern learning) | One new interaction per chapter; lore is also a pattern to learn | No fake depth via opaque randomness |
| Hooked loop | Trigger = story cliffhanger (internal), action = 1-tap run start, variable reward = story/loot draws, investment = journal + deck edits | No nag notifications, no absence punishment |
| Flow | Legible goal per run; ramp within run; visible optional assist toggle (Hades God-Mode style) | No secret rubber-banding |
| SDT (competence/autonomy/relatedness) | Show mastery stats; NEVER take the extraction choice away; story reacts to what you did | No paywalled power |
| Drive (purpose) | Each life is spent FOR something — "the life she gave to cross the river," not "run #37" | — |
| Variable-ratio rewards | Rare jackpot story cards (~1-in-N runs) — the reward is content | Never attach variable rewards to payment |
| Zeigarnik (open loops) | End sessions on cliffhangers + visible locked journal silhouettes | Loops must resolve through play, not purchase |
| Endowed progress (34% vs 19% completion) | Journal opens with Life One inscribed; "3 of 9 chronicled," never "0 of 6 remaining" | Endowment must be truthful |
| Loss aversion | Extraction UI shows exactly what's at stake — the satchel IS applied loss aversion | Losses only from in-run choices; nothing decays with absence |
| IKEA effect | Named/saved deck builds; player picks journal memory-illustrations | Don't sell assembly shortcuts |
| Peak-end rule | **Deaths end on a story sting and a beautiful card — the Hades move.** A lost run that ends on a great line is remembered as a good run | — |

## Ranked top-7 improvements (adopted roadmap order)

1. **Peak-end deaths/extractions** — every run ends on a story sting, win or
   lose (Hollow Court already does this for deaths; extend to retreats and
   wins with rotating lines + art).
2. **Apply the Part A text budget** to all story cards (prologue prose pass).
3. **Open loops at session end** — chapter cliffhangers, locked journal
   silhouettes.
4. **Reactive story lines** — conditional variants acknowledging the
   player's actual run ("she remembers the river").
5. **Endowed progress framing** everywhere.
6. **Sharpen the extraction decision UI** — the most dramatic screen in the
   game.
7. **Named deck builds + journal customization** (IKEA + investment).
